# Sistema de Gestão de Produtos em C

Sistema desenvolvido para gerenciamento de produtos, focado em praticar a linguagem C com o uso de **structs**, **ponteiros**, **vetores** e **modularização por funções**.

## Funcionalidades
- Cadastro de múltiplos produtos (com código, nome, preço de custo e preço de venda).
- Cálculo automático da margem de lucro.
- Relatório completo de todos os produtos cadastrados.
- Identificação automática do produto mais lucrativo.
- Filtro de produtos por faixa de preço limite.
